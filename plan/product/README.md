# plan/product

Product-inception artifacts, one directory per initiative:
`<initiative-slug>/{brief.md,prd.md,architecture.md}`.

Empty is normal. Inception is **opt-in and rare** — most work in this repo
starts from an implementation plan in `plan/development/`, not from a product
brief. This directory exists so that when an initiative does warrant one, it
has an obvious home rather than landing in `plan/development/` alongside
implementation plans.

Where an inception architecture document reaches a ratified decision, that
decision is promoted into `plan/architecture/`'s numbered document set; the
brief and PRD stay here.
